## O código para ser analisado:

```c
#include <stdio.h>
#include <stdlib.h>;

int Main()
{
    int idade = 20;
    printf( A idade do aluno eh: %d anos.. , idade);
    cout << endl;
    system("PAUSE");
    return 0;
}
```
1. O ponto e vírgula após chamar as bibliotecas não existe

2. O Main da função int main() deve ser minúsculo

3. No printf, é necessário que o conteúdo esteja entre aspas, ficando fora das aspas apenas as variáveis na ordem a serem chamadas.

4. A linha cout << endl não faz parte da linguagem C.
